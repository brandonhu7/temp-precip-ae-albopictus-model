# Code for "Investigating the Effect of Incorporating Precipitation in a Temperature-driven Model of Aedes Albopictus Population Dynamics"
> Brandon Hu, Michael A. Robert

**Paper:** Information will be added upon publication. 


## Overview

This repository contains the code used for the experiments described in the paper. It is provided to support reproducibility and serve as a reference for implementation. 

## Repository Structure

```
├── data processing and plots/   # Code used to process raw data and generate formatted plots
├── data/                        # Data and Model Outputs
├── models/                      # Models used for simulations
├── requirements.txt             # Python dependencies
└── README.md
```

## Requirements

This project was developed using Python 3.11.13 and requires the following packages:

- NumPy
- SciPy
- Pandas
- Matplotlib

Install the required packages with:

```bash
pip install -r requirements.txt
```

## Data

Mosquito ovitrap data comes from Le Goff et al. and is publicly available on the Global Biodiversity Information Facility (GBIF):
https://doi.org/10.15468/q4tq5q

Daily temperature and precipitation data was obtained from Météo-France:
https://meteofrance.re/fr/climat/normales/Réunion/gillot-aeroport
